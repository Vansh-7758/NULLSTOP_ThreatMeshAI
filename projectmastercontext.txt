🏛️ 1. Project Architecture & Capabilities Summary
ThreatMesh AI is an enterprise-grade autonomous software supply chain defense platform powered by a dual-layer AI governance engine, real-time graph reachability analysis, and dynamic 5-signal trust scoring.

📦 Platform Modules
MODULE 1 — WATCH (Executive Monitor & Real-Time Posture):

Executive Dashboard: Real-time Cyber Health Score, Total Packages, At-Risk Count, Active CVEs, and Open PRs.
Feature 3 — ADTG Adaptive Dependency Trust Scoring: Dynamic 5-signal software credit score (CVE Severity, EPSS Exploitation Probability, Public Exploit Availability, Maintainer Activity, and Release Cadence).
Feature 4 — Interactive Graph Reachability Analysis: Cypher graph walk analysis filtering theoretical vulnerabilities from 5-hop reachable attack paths from public endpoints.
Feature 6 — Attack Replay Timeline: Chronological simulation of supply chain compromise cascades.
Live Security Advisory Ticker: NVD, OSV.dev, and GitHub Security Advisory stream.
Dependency Trust Distribution (Donut Chart): Visual breakdown across Trusted (80-100), Watch (50-79), and At Risk (<50) tiers.
MODULE 2 — HUNT (Adversarial Red-Teaming & Threat Discovery):

Automated red-teaming agents testing supply chain depth, dependency confusion, and hidden backdoor triggers (e.g., CVE-2024-3094 xz-utils patterns).
MODULE 3 — DEFEND (Full-Spectrum AI Governance & Compliance Engine — Feature 7 Expansion):

Layer 1 (Inward AI Governance): Real-time prompt/response proxy evaluating 5 security policies (no_sql_injection, no_pii_leakage, no_jailbreak_attempt, no_unauthorized_tool_execution, no_hallucinated_cve).
Layer 2 (Full-Spectrum Compliance Engine):
5 Compliance Domains: Software (SBOM/Dependencies), Infrastructure (Cloud/Network), People & Access (IAM/RBAC/Training), Processes & Policies (IR/Change Control), Data (Privacy/GDPR/Encryption).
42-Question Assessment Bank: Weighted question engine evaluating organizational compliance.
Multi-Framework Alignment: Calculates instant compliance alignment percentages for ISO 27001, NIST CSF, GDPR, EU AI Act, and OWASP Top 10.
SBOM Technical Penalties: Dynamically penalizes domain scores based on technical SBOM vulnerabilities.
Claude AI Gap Analyzer: Generates executive summaries, plain-text audit reports, and AI remediation roadmaps.
🛠️ 2. Technical Stack & Infrastructure
Backend: FastAPI (Python 3.12), Asyncpg (PostgreSQL), Neo4j (Cypher Graph Database), Anthropic Claude API (claude-sonnet-4-6), Uvicorn on http://localhost:8000.
Frontend: Next.js 14 (App Router), React 18, TailwindCSS, Framer Motion, Recharts, Lucide Icons, Dev Server on http://localhost:3000.
Database Models: Scans, ScanPackages, ScanCVEs, AttackPaths, Predictions, Playbooks, CompanyProfiles, ComplianceAssessments, ComplianceReports, ComplianceSessions.
